# Daily Akari 共享题库

配合油猴脚本 `akari-archive-tool.user.js` 使用：把大家转换/录入过的题目放在这里，
别人不用重复转化或重新抄题。

## 朋友怎么用

1. 装上 `akari-archive-tool.user.js`
2. 打开 https://dailyakari.com 任意页面，点右下角「存档」→ 展开面板
3. 在「共享库」那一栏填仓库名（形如 `用户名/仓库名`），点「保存仓库」
4. 点「拉取所有题目」——本地没有的关卡会被补上，本地已有的**不会被覆盖**

拉取过一次后，这些题在归档列表里就显示成「游玩」，和站点原生题一样玩，成绩照常记录。

## 录了新题想共享回去

1. 面板里点「导出我的条目」，会下载一个 `akari-shared-*.json`
2. 把它里面的 `conversions` 合并进本仓库的 `data/puzzles.json`（只加新编号，别删别人的）
3. 提交（发 Pull Request，或把 json 直接发给仓库维护者合并）

## 合并规则（脚本侧）

- 以关卡编号为键，**只补本地没有的**；本地已有的一律保持原样，不会被共享库覆盖
- 每条都会校验：URL 结构、声明的行列数、解码后重新编码是否一致；不合格的条目会被忽略并在面板里列出编号
- 每次拉取都是手动触发，没有自动检查更新

## 数据来源

- 本仓库只用于个人之间交流做题，与 Daily Akari 官方网站无关 ;p
